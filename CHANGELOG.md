# Changelog

## 1.0.0 — 2026-10-07

First public portable release of ScreenInk for Windows.

- F8 screen capture and a drawing overlay with seven tools.
- Smooth pen ink, translucent highlighter, whole-stroke erasing, temporary laser, line, arrow pen, and rectangle.
- Undo/redo, retained pages during the session, per-tool preferences, and a compact dock on any edge.
- PNG export and clipboard copy without the toolbar or temporary pointers.
- A portable launcher and an optional offline blank whiteboard page.
- A detailed user guide, custom banner, scripted privacy-safe teaching demo, and reproducible packaging tools.
- Existing canvas, shortcut, toolbar, docking, and session-retention regression checks, also configured for Windows GitHub Actions.

The annotation background is a frozen screenshot, and drawings are session-only until exported. Touchscreen/stylus behavior and meeting-app capture compatibility require testing on the user's hardware and software.
